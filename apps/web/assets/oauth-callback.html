This page exists because myna normally listens on 127.0.0.1, which only works when your browser is on the same machine as myna. When it is not — over SSH, or authorizing from a phone — the code comes here instead and you carry it across yourself. Nothing is stored here: the code lives in the URL and never reaches a server log of ours, because the exchange happens on your machine, not this one.
